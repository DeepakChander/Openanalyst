# Docker & Containers

> Docker makes "works on my machine" a deployment strategy. Package your app
with its dependencies, run it anywhere. But Docker's simplicity hides real
complexity. A naive Dockerfile can be 10x larger and slower than it needs to be.

This skill covers Dockerfile optimization, multi-stage builds, Docker Compose
for development, security hardening, and production patterns. Key insight:
your Dockerfile is code. Review it, optimize it, version it.

2025 lesson: Containers aren't VMs. The patterns that work for VMs (install
everything, big base images) are anti-patterns for containers. Think small,
think immutable, think layers.

## Patterns

### Multi-Stage Build
Separate build and runtime for smaller images
**When:** Any compiled or bundled application

### Layer Caching Optimization
Order Dockerfile for maximum cache reuse
**When:** Any Dockerfile with dependencies

### Docker Compose for Development
Multi-container development environment
**When:** App with database, cache, or other services

**When:** Any production image

## Anti-Patterns

### Huge Base Images
Using full OS images when slim/alpine works
**Instead:** # WRONG: Full image
FROM node:20
FROM python:3.12
FROM ubuntu:22.04

# RIGHT: Minimal images
FROM node:20-alpine
FROM python:3.12-slim
FROM alpine:3.19

# BEST: Distroless (no shell, minimal attack surface)
FROM gcr.io/distroless/nodejs20


### Running as Root
Container process running as UID 0
**Instead:** # Create and use non-root user
RUN addgroup -S app && adduser -S app -G app
USER app

# Or use numeric UID
USER 1000:1000


### Latest Tag
Using :latest or no tag for base images
**Instead:** # WRONG
FROM node:latest
FROM node

# RIGHT: Pin major.minor at minimum
FROM node:20.10-alpine

# BEST: Pin digest for reproducibility
FROM node:20.10-alpine@sha256:abc123...


### Secrets in Image
Baking secrets into the image at build time
**Instead:** # WRONG: Secret in image
ENV API_KEY=sk_live_xxxxx
COPY .env /app/.env

# RIGHT: Runtime injection
# docker run -e API_KEY=xxx myimage

# RIGHT: Docker secrets
# docker secret create api_key key.txt
# In compose: secrets: [api_key]

# RIGHT: Mount read-only secrets
# docker run -v ./secrets:/run/secrets:ro myimage


### No .dockerignore
Missing .dockerignore file
**Instead:** # Always create .dockerignore
node_modules
.git
.env*
*.md
tests
coverage
