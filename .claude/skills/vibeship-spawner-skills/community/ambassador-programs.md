## Ambassador Recruitment

### Finding Candidates
- Most active community members
- Quality content creators
- Helpful forum responders
- Event organizers
- Existing power users

### Application Process
1. Open application form
2. Community manager review
3. Check existing activity
4. Interview top candidates
5. Trial period (1 month)
6. Full onboarding

### Application Questions
- Why do you want to be an ambassador?
- What content/activities will you create?
- How do you currently use [product]?
- Link to existing community contributions
- Time commitment available?

### Red Flags
- Only want free stuff
- No existing community presence
- Can't articulate genuine interest
- History of community issues
- Unrealistic commitments

### Green Flags
- Already helping others
- Authentic enthusiasm
- Quality over quantity
- Aligns with values
- Realistic about time

## Anti-Patterns

### Free Labor Disguised as Ambassador Program
Expecting work without fair value exchange
**Why it's bad:** Ambassadors feel used.
Best people leave.
Reputation damage.
Attracts wrong people (freebie hunters).


### Set It and Forget It
Launching program then not managing it
**Why it's bad:** Ambassadors disengage.
No accountability.
Program dies quietly.


### Too Many Ambassadors
Accepting everyone to inflate numbers
**Why it's bad:** Dilutes meaning.
Can't support everyone.
Quality drops.
Ambassadors feel unspecial.

### [HIGH] Ambassador does something that reflects poorly on brand

**Situation:** Public ambassador behavior damages reputation

**Why it happens:**
Ambassadors represent your brand.
Their actions are associated with you.
Viral moments spread fast.


**Solution:**
```
## Managing Ambassador Risk

### Prevention
- Clear code of conduct
- Social media guidelines
- Regular check-ins
- Values alignment in recruitment

### Response Protocol
1. Assess situation quickly
2. Private conversation first
3. If public: Acknowledge you're reviewing
4. Fair investigation
5. Proportional action
6. Learn and update policies

### Levels of Response
| Severity | Action |
|----------|--------|
| Minor | Private feedback |
| Moderate | Warning, coaching |
| Serious | Suspension pending review |
| Severe | Immediate removal |

### After Removal
- Brief public statement if needed
- No public attacks
- Update recruitment process
- Review similar situations

```

**Symptoms:**
- Ambassador post goes viral negatively
- Community complaints about ambassador
- Media reaching out
- Brand association damage

### [MEDIUM] High turnover in ambassador program

**Situation:** Ambassadors leaving faster than joining

**Why it happens:**
Not enough value for effort.
Better opportunities elsewhere.
Burnout.
Lost interest in product.


**Solution:**
```
## Reducing Ambassador Churn

### Exit Interviews
- Always conduct when ambassadors leave
- Anonymous survey option
- Look for patterns

### Common Reasons and Fixes
| Reason | Fix |
|--------|-----|
| Not enough value | Increase rewards, access |
| Too much work | Reduce requirements |
| No recognition | More public appreciation |
| Product issues | Feed back to product team |
| Life changes | Graceful alumni status |

### Retention Tactics
- Regular engagement
- Clear progression path
- Meaningful rewards
- Community among ambassadors
- Direct access to team

### Healthy Churn
- Some churn is natural
- Target: <30% annual turnover
- Replace quickly
- Alumni network

```

**Symptoms:**
- Ambassadors going inactive
- Not hitting activity minimums
- Resignations increasing
- Difficulty recruiting

### [MEDIUM] Ambassador program becomes exclusive club

**Situation:** Existing ambassadors block new voices

**Why it happens:**
Long-term ambassadors territorial.
Program becomes insider club.
New perspectives blocked.


**Solution:**
```
## Preventing Ambassador Cliques

### Program Structure
- Regular cohorts (quarterly intake)
- Term limits with re-application
- Diverse recruitment
- Cross-cohort activities

### Culture Building
- Mentorship (senior → new)
- Collaborative projects
- Shared recognition
- Inclusive communication

### Governance
- Clear rules for all
- No unofficial hierarchies
- Ambassador feedback council
- Staff oversight

```

**Symptoms:**
- Same people dominate
- New ambassadors feel excluded
- Resistance to new members
- We've always done it this way

### [HIGH] Ambassadors secretly working with competitors

**Situation:** Ambassador promoting or working for competition

**Why it happens:**
Conflict of interest.
Insider access being shared.
Divided loyalty.


**Solution:**
```
## Conflict of Interest Management

### Clear Policy
- Define competing products
- Disclosure requirements
- Exclusivity expectations
- Review process for conflicts

### Application Screening
- Ask about other affiliations
- Check public profiles
- Reference checks
- NDA for sensitive access

### Discovery Protocol
1. Confirm the situation
2. Private conversation
3. Assess intent and impact
4. Decision: allow, modify, or remove
5. Update policies if needed

### Nuance
- Multi-product ambassadors can be OK
- Context matters
- Don't overreact
- Fairness in decisions

```

**Symptoms:**
- Ambassador promoting competitor
- Reduced enthusiasm
- Access misuse
- Community reports
