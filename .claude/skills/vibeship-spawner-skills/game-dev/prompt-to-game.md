## Patterns

### Component-by-Component Prompting
Build games piece by piece, testing after each generation

### Reference Existing Games Pattern
Use well-known games as shorthand for mechanics

### Specify Framework in Every Prompt
Always declare your framework and version

### Seed Lock and Document Pattern
Save everything when something works

### Negative Constraints Pattern
Tell AI what NOT to do to avoid common issues

### Refactor at Threshold Pattern
Know when to stop prompting and restructure

### Three-Prompt Workflow
Rapid prototyping in three stages

### Security-First Validation
Treat all AI code as untrusted


## Anti-Patterns

### Mega-Prompt Everything
Asking for entire game in single prompt
**Why it's bad:** Produces inconsistent, spaghetti code. Features conflict. Hard to debug because everything is intertwined. Context window limits cause forgotten features.


### Accepting Code Without Understanding
Using AI code you don't understand
**Why it's bad:** Cannot debug when it breaks. Cannot extend safely. May contain security vulnerabilities. Will fail in production when no one knows how it works.


### Sunk-Cost Prompting Loop
Continuing to prompt because you've invested time
**Why it's bad:** "I've spent 2 hours prompting, I can't stop now." This is the AI programming sunk-cost fallacy. Sometimes the answer is to reset and start fresh.


### Ignoring Hallucinated APIs
Not checking if AI-referenced methods exist
**Why it's bad:** 5-21% of AI suggestions include hallucinated dependencies. AI trained on old documentation. Methods that don't exist, wrong signatures, deprecated patterns.


### Version Blindness
Not specifying or checking framework versions
**Why it's bad:** AI trained on Phaser 2 generates Phaser 2 code for your Phaser 3 project. Deprecated patterns, wrong APIs, subtle bugs from version differences.


### No Testing Between Prompts
Chaining prompts without running the code
**Why it's bad:** Errors compound. Later prompts build on broken foundation. Debug session becomes impossible when you don't know which of 10 prompts broke things.
